# Speed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut first-load JS by at least 35%, make the home world map cheaper to paint on phones, make hot server queries and writes grow-proof, and cache and compress static files properly. Nothing visible changes.

**Architecture:**
- **Client:** student routes become `lazy()` and are warmed up when idle. The tutor tab is lazy. English strings load on demand. A budget script guards the entry size.
- **Server:**
  - SQLite pragmas plus two schema indexes.
  - Scoped queries with equivalence tests.
  - Static serving moves into `mountStatic(app, root)`, with immutable caching, a 404 for missing assets, pre-compressed files from a Vite plugin, and env-switched dynamic gzip.
- **World map:** measured in a browser before and after: a static grain tile and off-screen segment hiding.

**Tech Stack:** React 19, react-router 8 (data router, view transitions), Vite (rolldown) + vite-plugin-pwa, i18next, Hono 4.13 on Bun 1.4 (`@hono/bun` serveStatic, `hono/compress`), Drizzle + bun:sqlite, bun test.

**Spec:** `docs/superpowers/specs/2026-11-20-speed-design.md`

## Global Constraints

- **No visible change.** API response shapes stay identical. No new runtime or dev dependencies (use `node:zlib`).
- **Lazy pages:** `LessonPage`, `LessonStudyPage`, `ReviewPage`, `LeaderboardPage`, `ProfilePage` and `BattlePage` are lazy. `HomePage` and `LoginPage` stay eager. `Markdown` stays a normal import.
- **Suspense fallback** is the existing `PageSpinner`.
- **Every lazy chunk stays precached** by the PWA. The existing globPatterns already match `**/*.js`; don't change globPatterns.
- **SQLite pragmas:** `synchronous = NORMAL`, `busy_timeout = 5000`, `cache_size = -20000`, `temp_store = MEMORY`. No `mmap_size`.
- **Hashed assets:** `Cache-Control: public, max-age=31536000, immutable`, only on a successful `/assets/*` hit. A missing `/assets/*` returns 404 JSON-free plain `Not Found`. The shell, `sw.js`, `registerSW.js`, `workbox-*.js` and `manifest.webmanifest` keep `no-cache`.
- **Pre-compression:** `.br` and `.gz` for `js, css, svg, json, webmanifest` files over 1024 bytes, written by a Vite plugin placed after `VitePWA`.
- **Dynamic compression:** `HTTP_COMPRESS` (default on; `false`/`0` turns it off) gates `hono/compress` on `/api/*` and the shell. Never compress `text/event-stream`, audio, or responses that already have `Content-Encoding`.
- **Stale chunks:** reload once on `vite:preloadError`, guarded by `sessionStorage` key `wr-chunk-reload`.
- **Bundle budget:** the measured post-job size plus 10%, and at least 35% below the baseline of 1.3 MB raw (the entry plus modulepreloads).
- **i18n in tests:** tests must not import `src/lib/i18n.ts` (it crashes under bun). Put testable logic in pure modules.

## Review Focus

- **Language:** an English user on a cold load sees English on the first paint, with no Dutch flash; switching nl→en→nl in the profile works. (Task 3: `ensureLocale` test, plus a manual check.)
- **Offline:** a page opened offline after one online visit still loads its lazy chunk from the precache. (Task 2: a build check that `dist/sw.js` lists every lazy page chunk.)
- **Tutor:** the tutor chat still streams token by token in production with `HTTP_COMPRESS` on. (Task 6: a test that the chat route response has no `Content-Encoding`.)
- **Audio:** lesson audio Range requests still return 206 with correct bytes when compression is on. (Task 6 test.)
- **Review queue:** it returns identical items and intervals for a user with reviews across several lessons, including a lesson in an unpublished reader. (Task 5 equivalence test.)
